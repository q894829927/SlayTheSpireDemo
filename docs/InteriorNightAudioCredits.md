# Interior night audio attribution

**Composition:** Ludwig van Beethoven, Piano Sonata No. 14 in C-sharp minor, Op. 27 No. 2, I. Adagio sostenuto (Moonlight Sonata).

**Performance:** Paul Pitman, for [Musopen](https://musopen.org/).

**Source and recording license:** [Wikimedia Commons file and licensing page](https://commons.wikimedia.org/wiki/File:Ludwig_van_Beethoven_-_sonata_no._14_in_c_sharp_minor_%27moonlight%27,_op._27_no._2_-_i._adagio_sostenuto.ogg), accessed 2026-09-07. The page identifies the recording as released into the public domain by Musopen, with permission correspondence, and requests attribution. The in-game night overlay credits Paul Pitman and musopen.org.

**Project asset:** `/Game/House/InteriorNight/SW_MoonlightSonata_Pitman`.

The downloaded Ogg recording was converted to 44.1 kHz, stereo, 16-bit PCM WAV for Unreal import. The complete first movement is retained; playback loops while night is active. Original download and intermediate WAV are local files in Saved, excluded from version control. The imported SoundWave is referenced by the map's day/night controller so it is included with the map when cooked.
