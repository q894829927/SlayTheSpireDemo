## 契约与迁移

- `UCardData.bAutoGenerateDescription` 默认 `true`，已有资产加载时同样采用该默认值，无需重新保存卡牌资产。
- 描述按 `Effects` 数组顺序逐项生成，每个 Effect 一行；重复类型保留为独立语句。
- Effect 提供可本地化的中文 `FText` 模板。数值沿用只读 Gameplay preview，升级读取该实例的升级配置，不复制战斗真值。
- Damage 自动描述包含实际配置的多次攻击次数；SelectExhaust 使用实际基础/升级选择模式和数量。
- 状态名称来自 `UStatusData.DisplayName`，本地化该名称即可同步更新卡牌中的状态名称。
- 本次通过 UE Python commandlet 编辑并保存五个状态资产的 DisplayName：Strength→力量、Weak→虚弱、Vulnerable→易伤、Dexterity→敏捷、Frailty→脆弱。状态 ID、Modifiers 和战斗数值不变。
- 卡牌最终配置目的地为 `Exhaust` 时，末尾自动添加“消耗。”。消耗手牌的 Effect 与本牌消耗是两个独立规则。
- 每个 Effect 独立解析参数，允许多个 Effect 使用默认同名参数；目标预览通过 `EffectIndex` 限定覆盖范围，保留原有富文本数值比较样式。
- 生成结果进入现有冻结 DTO / Presentation Snapshot 管线，不让 UI 执行 Gameplay，不修改队列和结算逻辑。

旧 `Description` 序列化字段保留。在确有自定义整句需求时显式关闭 `Auto Generate Description`，编辑器才显示 `Custom Description Format`，恢复原有模板及参数校验；自定义模式仍由作者完整维护描述。

本契约替代自动模式下此前“每张牌手工填写模板、参数名必须全卡唯一”的规则，包括 C0 Description Compatibility Amendment 的手工描述要求。该旧规则仅适用于显式自定义模式。SelectExhaust 的旧 None 参数不影响自动模式。

## 作者操作

1. 打开卡牌 Data Asset，保持 `Auto Generate Description` 开启。
2. 在 `Effects` 中添加、删除、拖动条目，并设置其基础/升级属性。
3. 将 `Default Destination` 设为 `Exhaust` 可使本牌使用后消耗，同时自动显示对应关键字。
4. 保存后重新进入战斗，卡面读取新配置。已冻结的历史播放记录保持原样。

示例：Damage(6) → Draw(2)，目的地 Exhaust：

```text
造成 6 点伤害。
抽 2 张牌。
消耗。
```

模板使用稳定 namespace/key 的 `NSLOCTEXT`，组合保留 `FText` 格式化历史。以后在 Localization Dashboard 的目标中纳入 `Source/SlayTheSpireDemo` 的源文本以及状态资产文本，再采集和翻译。本次不新增翻译语言或修改项目文化设置。

## 扩展与回退

新增或修改 Effect 时，必须遵守 `Source/SlayTheSpireDemo/Cards/AGENTS.md`，在同一次变更中同步行为、自动描述、参数、下方固定文本表及相关聚焦测试。只完成 `BuildActions` 不算完成 Effect。

新 Effect 必须实现 `GetAutoDescriptionFormat`；默认 `BuildAutoDescriptionArguments` 沿用既有 preview 参数，可按需覆盖。未提供自动文本的 Effect 在资产验证中报告错误，不通过类型集中分支或卡牌 ID 特判。不得通过关闭自动描述绕过新增 Effect 的文本实现要求。

`bAutoGenerateDescription=false` 是单张卡牌的显式兼容回退，不依赖空字符串推断。已有用户资产修改保持原样。

## Effect 固定中文文本规范

下表的 `{Value}` 表示该 Effect 的局部数值占位符；实际参数名可沿用 `DescriptionArgumentName`，不要求全卡唯一。数字、次数和模式读取有效的基础/升级属性，不把示例数值写死到文本中。

| Effect / 条件 | 固定文本 | 变量来源 |
| --- | --- | --- |
| Damage，单次 | `造成 {Value} 点伤害。` | 当前只读伤害预览 |
| Damage，多次 | `造成 {Value} 点伤害，共 {Hits} 次。` | 每次伤害预览、有效 HitCount |
| GainBlock | `获得 {Value} 点格挡。` | 当前只读格挡预览 |
| Draw | `抽 {Value} 张牌。` | 有效 DrawCount |
| GainEnergy | `获得 {Value} 点能量。` | 有效能量增量 |
| ApplyStatus，自身 | `获得 {Value} 层{Status}。` | 有效 Amount、StatusDefinition.DisplayName |
| ApplyStatus，敌方目标 | `给予目标 {Value} 层{Status}。` | 有效 Amount、StatusDefinition.DisplayName |
| SelectExhaust，随机 | `随机消耗 {Count} 张手牌。` | 有效 SelectionMode / SelectionCount |
| SelectExhaust，玩家选择 | `选择 {Count} 张手牌消耗。` | 有效 SelectionMode / SelectionCount |
| 本牌消耗，由卡牌 resolver 追加 | `消耗。` | 卡牌 ResolveDestination 为 Exhaust |

实现新效果时沿用上述中文术语、单位和句号风格；新的行为需要新的固定句式时扩充本表。模式、目标或升级会改变含义时，提供相应本地化句式，不能只换数字而保留错误措辞。状态等名称来自可本地化的定义文本，不能在 Effect 中按 ID 翻译名称。

Effect 只贡献自身语句；卡牌 resolver 按数组顺序组合并追加本牌“消耗。”。同一语句内的视觉自动折行由 UMG 可用宽度控制，不能为修复排版在 Effect 中插入硬换行或改写数值。

本牌末尾“消耗。”的富文本使用 `DT_BattleCardTextStyles` 的 `Exhaust` 行，颜色为 sRGB `RGB(239, 200, 81)` / `#EFC851`，不透明。DataTable 的 LinearColor 存储经过 sRGB→线性转换的值，字体及字号沿用 Default 行。纯文本保持“消耗。”，仅 RichDescription 加 `<Exhaust>…</>`，并保留本地化 FText 历史。消耗其他手牌的 Effect 句子保持原有颜色。
